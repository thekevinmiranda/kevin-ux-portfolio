Persona — Free Personal vCard / Freelancer Portfolio Template

Concept: a one-page personal site that feels like a person, not a SaaS landing page.
It leans editorial and warm rather than the usual cold, centered, gradient-on-white
portfolio. The layout alternates airy "paper" sections with two immersive dark
"forest" bands (services and testimonials) to give the scroll a real rhythm, and the
photography is framed with an offset marigold block so the person — not a hero
gradient — is the first thing you see.

Palette (deep-forest ink + warm marigold on warm paper):
  #14231C  ink / footer            #1C3A2E  forest (dark sections)
  #244A3A  forest card surface     #F4F1E8  paper (main light bg)
  #ECE7D9  paper-2 (alt bg/cards)  #E6A017  marigold (accent)
  #B0512C  clay (rare warm accent) #6E8377  sage (muted text)

Font pairing: Bricolage Grotesque (characterful display — the big name, headings, and
quotes) paired with Hanken Grotesk (a warm, legible grotesque for body and UI).
Deliberately avoids Inter / Space Grotesk and the cream+serif+terracotta cliché.

Build: Bootstrap 5 (self-hosted, reset + grid only), vanilla JavaScript with
guard-claused init functions (no jQuery), hand-drawn inline SVG icons (no icon fonts),
and local images only — so it deploys clean on strict-CSP demo hosts.
